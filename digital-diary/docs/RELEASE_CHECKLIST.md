# Release Checklist

Every release must satisfy the following criteria before deployment. This ensures that the project remains completely stable and regressions never reach production.

- [ ] `npm install`
- [ ] `npm run lint`
- [ ] 0 errors
- [ ] `npm run typecheck`
- [ ] 0 errors
- [ ] `npm run build`
- [ ] 0 errors
- [ ] Mobile verified
- [ ] Desktop verified
- [ ] Dark mode verified
- [ ] GitHub sync verified
- [ ] Search verified
- [ ] Images verified
- [ ] Export verified
- [ ] Accessibility checked
- [ ] Documentation updated
- [ ] Changelog updated
- [ ] Deploy
