# The Digital Diary Roadmap

> **Capture memories. Find them later. Enjoy revisiting them.**

This roadmap defines the boundary of what The Digital Diary is and what it will never be. New features are added only if they support the core promise and have earned their place through real-world friction.

---

# 1. Journal Management (Core)

These are essential.

### Create Entry
* New entry
* Choose **Event Date**
* Auto title (optional)
* Markdown editor

### Edit Entry
* Edit title
* Edit content
* Edit event date
* Edit tags
* Edit collection

### Delete Entry
Don't permanently delete immediately.
Instead: `Delete` → `Move to Trash` → `Restore` → `Delete Permanently`. Just like Windows Recycle Bin.

### Duplicate Entry
Useful for templates. Example: `Daily Reflection` → `Duplicate` → `New copy`.

### Favorite Entry
Star important memories. Examples: Graduation, First Job, Birthday.

### Pin Entry
Pin a few entries to the dashboard.

---

# 2. Writing Experience

### Rich Markdown
* Headings, Lists, Checklists, Code blocks, Quotes, Tables, Horizontal rules.

### Drag & Drop Images
Simply drag an image. Done.

### Paste Images
Ctrl + V

### Auto Save
Every few seconds.

### Draft Recovery
If browser crashes. Recover.

### Focus Mode
Hide navigation. Only writing.

---

# 3. Organization

### Collections
Examples: Journal, Projects, Travel, Books, Ideas.

### Tags
Unlimited. Examples: college, family, placement, health, coding.

### Archive
Archive old entries without deleting.

### Trash
Recover accidentally deleted entries.

---

# 4. Browsing

### Timeline
Main way to revisit life.

### Calendar
Click date. Open entry.

### Search
Search by: title, content, tags, date, year, month.

### Filters
Examples: Only Favorites, Only Travel, Only 2025, Only Projects.

---

# 5. Reading

### Reading Mode
Beautiful typography. Like reading a book.

### Previous / Next Entry
Easy navigation.

### On This Day (v2)
Optional.

# 11. Quality of Life

Character count, Word count, Reading time, Copy Markdown, Copy Link, Print entry, Fullscreen editor, Breadcrumbs, Loading skeletons, Empty states, Undo/Redo.

---

# Features I would NOT add

These don't align with Dear Diary's purpose:
* AI writing assistant, Chatbot
* Social feed, Comments, Likes, Followers
* Notifications, Gamification, Streaks
* Mood analytics dashboards
* Weather (unless you personally find it valuable)
* Collaboration, Multiple users

---

# Memory Attachments (Strong Recommendation)

Each diary entry should support:
* Images
* PDFs
* Audio recordings
* Videos (stored in GitHub if practical, or referenced)

Imagine opening an entry from 2024 and seeing:
`Trip to Goa`
`Photos (12)`
`Boarding Pass.pdf`
`Voice Memo`
`Hotel Receipt`

That turns the diary into a complete memory archive.

---

## Stewardship

The Digital Diary is feature complete.

From this point onward:
- Bugs may be fixed.
- Performance may be improved.
- Accessibility may be improved.
- Documentation may be improved.
- Existing features may be refined.

No new feature may be added unless it is supported by repeated real-world usage and documented evidence.
